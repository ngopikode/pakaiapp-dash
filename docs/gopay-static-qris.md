# (NEW!) GoPay Static QRIS

You can now use GoPay Static QRIS in your business! Download the file, and use it in your various business flows e.g. for bazaars, offline stores, and many others.

What's different with Midtrans's Static QRIS is that you can use it as part of your business flow and still programmatically automate your workflows with our various APIs e.g. Refund APIs, Transaction Report APIs, settlement notification webhook, etc.

<br />

# Activating GoPay Static QRIS

<br />

1. Go to [Dashboard > +Payment Methods](https://dashboard.midtrans.com/new_payment_method), and activate Static QRIS feature. Do note that you need to have your GoPay payment method active first in order to be able to activate GoPay static QRIS.

   <Image align="center" width="50% " src="https://files.readme.io/030e44a81e156df7e84cc0c67b6c6eda143bf2b282c59bf76247c10bdaf5a90c-image.png" />
2. Continue with the steps, no additional docs or addendum needed to be signed. It will take 1 working day to KYC and activate.

<br />

# Accessing Static QRIS Page

<br />

After onboarding is done, go to Dashboard > + Payment Methods. A new tab ‘Manage static QRIS’ should show up if you have finished the onboarding process.

# Generating Static QRIS

<br />

1. In the Manage Static QRIS Page, click Generate. Fill in the identifier - this will show up in your transactions reports under the PoP Name column.

   <Image align="center" width="75% " src="https://files.readme.io/30c523a87ec080c00bf10c307188f1bbbd46d99b319707bde10470c5a19b5a79-image.png" />
2. Once you have completed the step before, your Static QRIS will show up in your Static QRIS List. Click the arrow button to get your QRIS in PDF format. You can also modify the identifier via the pencil icon in the Action column.

   <Image align="center" width="75% " src="https://files.readme.io/cb1287ccad9d137f05b6a1aa845684adc0b7fa3a517e9199d71e39bb1d16e357-image.png" />

<br />

# Managing Transactions

<br />

* Just like dynamic QRIS transaction, you can manage, refund, and download reports of your QRIS transactions via Transaction page. Do note that with Static QRIS, there will be no order created first as merchant will only receive settlement notifications. Hence, order ID is not modifiable.

  <Image align="center" width="250px" src="https://files.readme.io/622b7ea2a6a6d12a31c3606a943836e3c63ce7624903d70316abe969f8df887c-image.png" />

<br />

* For every new payments, you will get a payment notifications via email and HTTP notification.
